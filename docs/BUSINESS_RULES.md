# 消防署勤務・システム業務ルール仕様書 (Business Rules)

このドキュメントは、本システム（消防署向け勤怠・勤務表管理システム）における、独自の業務ルールや絶対に守るべき計算ロジック、ドメイン知識をまとめたものです。
**開発者およびAIアシスタントは、システムの機能追加や修正を行う前に必ずこのファイルを参照し、既存のルールを破壊しないように注意してください。**

## 1. 勤務サイクルの基本ルール
- **28日周期**: 勤務表は「28日」を1つのサイクル（周期）として管理する。月単位の管理とは別に、ローテーションは28日を基準に回る。
- **起算日**: サイクルは特定の起算日（例: `2026-04-01`）からスタートし、以降28日ごとに「第2サイクル」「第3サイクル」と連なっていく。

## 2. 勤務区分・シフト記号の定義
システム上で用いられる主要なシフト記号とその意味は以下の通り。

- **当**（当務）: 24時間勤務（8:30〜翌8:30）。所定労働時間は15.5時間として扱う。
- **日**（日勤）: 8時間勤務（8:30〜17:15）。所定労働時間は7.75時間として扱う。
- **明**（明番）: 当務の明け日（勤務終了日）。
- **休**（週休）: 所定の休日。
- **有**（年休）: 年次有給休暇。
- **特**（特休）: 特別休暇。
- **公**（公休）: 祝日などの公の休み。
- **張**（出張）: 出張扱い。
- **病**（病休）: 病気による休暇。

## 3. 休暇（年休・特休）の消化ルール【超重要】
休暇を取得した際の日数計算（残日数のマイナスや、取得日数の集計）は、以下の厳密なルールに従う。

1. **当番勤務者（一当番の休暇）**
   - 1回（一当番）の休暇を取得した場合、**「2日分（16時間）」の消化**として計算する。
2. **日勤者（日勤の休暇）**
   - 1回の休暇を取得した場合、**「1日分（8時間）」の消化**として計算する。
3. **時間休**
   - 時間単位で休暇を取得した場合、**「取得した時間 ÷ 8.0 日」の消化**として計算する。（例：2時間取得＝0.25日の消化）
   - ※時間休の計算時、勤務時間帯に被る「休憩時間」分は消化時間から除外されるロジック（`calculateHourlyLeaveHours`）が存在する点に注意すること。

## 4. 残日数（有給・特休）の管理方式
- 現在、データベース上の残日数（`annual_leave_balance` など）は、休暇の承認と同時にシステム側で自動的に減算（上書き更新）する仕組みは**持っていない**。
- 代わりに、管理者が手動で残日数を更新（再登録）する運用を基本としている。
- 出勤簿等の出力時には、このルールに基づいた「消化日数」が精密に計算・表示されなければならない。

## 5. UI / 画面構成のルール
- **出勤簿（Ledger）**: 個人の1ヶ月間の勤務実績、休暇消化日数、超勤時間などを出力・印刷するための正式な帳票。
- **勤務表（Roster Grid）**: 28日周期のスプレッドシート型UI。小隊（A日/B日）ごとの全職員の配置、当番回数、休暇取得数（個人ごとの集計）を右端の列に表示する。
- **週休と年休の管理は「個人ごと」**であるため、勤務表における各日の「小隊全体での合計取得数」として縦に足し上げる表示は行わない（当番出勤者数の合計などは縦に表示する）。
