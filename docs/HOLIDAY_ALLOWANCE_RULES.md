# 祝日勤務における手当（休日給）計算ロジック仕様書

本システムにおける交代勤務者（1部・2部）の「祝日手当（休日給）」自動計算およびスライド（振替）処理の仕様についてまとめました。

---

## 1. 基本定義

### 対象とする休日 (`holidayType`)
手当の対象となる休日は以下の2種類に分類されます：
1. **国民の祝日 (`national`)**: 祝日法に規定された祝日、国民の休日、および振替休日。
2. **条例による年末年始休日 (`ordinance`)**: 12月29日〜12月30日、および1月2日〜1月3日。（※1月1日は「元日」であるため `national` に分類されます）

### 勤務区分
- **当 (当務)**: 24時間勤務（8:30〜翌8:30）。
- **非 (非番)**: 当直勤務の翌日。朝に勤務（8:30まで）が発生します。
- **日 (日勤)**: 日勤（交代勤務ではない職員。手当算出の対象外）。

---

## 2. 当日勤務時の手当支給ルール

祝日または条例休日の当日に、あらかじめ指定されていたシフトパターン（基準勤務）に基づいて判定されます。

### ① 基準が「当」の日に祝日・休日が重なった場合
- **実際に勤務した場合**: **12.0時間** の手当が支給されます。
- **公休・週休を取得した場合**:
  - `national`（国民の祝日）の場合：**スライド処理**（後述）の対象となり、スライドキューに送られます。
  - `ordinance`（条例休日）の場合：スライドせず、手当は消滅（対象外）となります。
- **有給・病休・特休を取得した場合**:
  - 勤務していないため、手当は不支給（カット）となります。

### ② 基準が「非」の日に祝日・休日が重なった場合
非番日にあたる日は、前日に当直勤務をしていたかどうかに基づいて判定されます。
- **手当時間基準**:
  - 年末年始期間（12/29〜12/31, 1/2〜1/3）：**3.5時間**
  - 通常の祝日：**4.0時間**
- **支給判定条件**:
  - **前日に実際に当直勤務を行っていた場合**（前日休・公・週や休暇を取得していない）：
    - 当日の実際のシフトが「休」「公」「週」「休暇」であっても、朝の勤務実績があるため **3.5時間 / 4.0時間** が全額支給されます。
  - **前日に勤務していなかった場合**:
    - 当日「休」「公」「週」かつ `national`（国民の祝日）であれば、**スライド処理**（後述）の対象となりスライドキューに送られます。
    - 当日「休暇」を取得した、または平日扱いの場合は、手当は不支給（カット）となります。

---

## 3. スライド（振替）処理ルール

国民の祝日（`national`）に勤務予定だった（「当」または「非」）が、その日が「週休」「公休」「代休」などの理由で勤務しなかった場合、その手当枠は**「それより後の直近の勤務日」**へスライド（振替）して支給されます。

### ① 「当」（12時間枠）のスライド
1. 祝日の翌日以降、最初に巡ってくる**基準が「当」である日**を順次探索します。
2. 探索先の日が、本来の祝日や他の休日（休・公・週）ではなく、手当が未割り当てである日を見つけます。
3. その探索日に休暇（有給・病休・特休・代休など）や休日（休・公・週）が入っていた場合は、**手当は不支給（カット）**となり、**再スライドは行われません**。
4. 正常に勤務した日であれば、その日に **12.0時間** の「スライド分」手当が支給されます。

### ② 「非」（3.5 / 4.0時間枠）のスライド
1. 祝日の翌日以降、最初に巡ってくる**基準が「非」である日**を順次探索します。
2. 探索先の日が、本来の祝日や他の休日ではなく、手当が未割り当てである日を見つけます。
3. その探索日に休暇や休日が入っていた場合は、**手当は不支給（カット）**となり、**再スライドは行われません**。
4. 正常な非番日（前日に当直して朝勤務した日）であれば、その日に **3.5時間 / 4.0時間** の「スライド分」手当が支給されます。

## 4. テスト検証パターン例（ドメイン仕様）

### 例1. ゴールデンウィーク（GW）パターン（スライドの発生）
5月4日（祝日・当直日）および5月5日（祝日・非番日）に休み（公休・週休）を取り、5月6日（振替休日）に出勤した場合：
- **5月6日（祝日）**: 当直勤務したため、**当日分 12.0時間** 支給。
- **5月7日（非当直・非祝日）**: 5月5日分の「非番 4.0時間」がスライドし、**スライド分 4.0時間** 支給。
- **5月8日（当直・非祝日）**: 5月4日分の「当直 12.0時間」がスライドし、**スライド分 12.0時間** 支給。

### 例2. 年末年始の条例休日消滅パターン
年末年始の条例休日（12/31, 1/1など）に休みを取得した場合：
- 国民の祝日ではないためスライドせず、手当は**消滅（対象外）**となります。
- ただし、1月2日（条例休日）に当直勤務をした場合は、**当日分 12.0時間** が支給されます。
- 1月3日（条例休日）が非番で、前日（1/2）に当直勤務していた場合は、**当日分 3.5時間**（年末年始基準）が支給されます。

### 例3. 代休・休暇取得時の手当カットパターン
スライド先の日（例：5月8日）に、本人が代休（`compensatory`）を取得して休んだ場合：
- スライド先で勤務していないため手当は **0時間（カット）** となり、それ以降の日へ**再スライドすることはありません**。
